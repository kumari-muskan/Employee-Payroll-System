# Employee Payroll System

## About the Project
A console-based Employee Payroll System developed using Java to demonstrate the practical implementation of Object-Oriented Programming concepts.

## Features
- Add employees
- Remove employees using Employee ID
- Display employee records
- Calculate salary for full-time employees
- Calculate salary for part-time employees

## OOP Concepts Used
- Abstraction
- Encapsulation
- Inheritance
- Polymorphism
- Method Overriding
- Constructor Chaining

## Technologies Used
- Java
- ArrayList
- Core Java

## How to Run

1. Clone the repository.
2. Open the project folder in the terminal.
3. Compile the program:

   `javac Main.java`

4. Run the program:

   `java Main`
